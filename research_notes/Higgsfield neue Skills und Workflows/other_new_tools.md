### Inferences
- The 2.1.274 timeout fix removes a real failure mode for hosted video MCPs (Higgsfield, Runway, Kling) whose jobs can exceed five minutes; the report's rule "Zeitüberschreitung: `higgsfield generate wait <id>`, nie denselben Job doppelt senden" remains correct, but users should also set a per-server `timeout` and run ≥ 2.1.283.
- 2.1.283's image-to-file change lets Claude pipe MCP-returned previews (e.g., keyframes) straight into ffmpeg/contact-sheet scripts, which strengthens the frame-based QA loop in the template.
- The 16 Sep Cowork merge makes the report's three-column surface table ("Claude-App mit Connectors | Cowork | Claude Code") partly outdated for Pro/Max users; Resolve and Blender control still need local Claude Code/Desktop because both MCPs are local.
- Claude Design/Docs/Slides in any conversation can produce the F1–F3 approval material (concept deck, look bible, storyboard doc) inside the chat.
- Syncing claude.ai skills into terminal sessions (2.1.275) can load a second copy of the Higgsfield skill (with its "Don't pre-estimate cost" rule) next to a project skill; the template's budget override should therefore stay explicit, or sync can be switched off per the documented setting.
